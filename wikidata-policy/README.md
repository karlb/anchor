# Wikidata policy notes

Summaries of the Wikidata pages most relevant to this project's editing of
Wikidata (sense-linking via `write.py`). One file per page; each links back to
its source URL and notes the retrieval date.

**How to edit** — conduct, permissions, and batch mechanics:

| File | Page | Status |
|------|------|--------|
| [mass-editing-policy.md](mass-editing-policy.md) | Requests for comment/Mass-editing policy | Proposed (RfC) |
| [edit-groups.md](edit-groups.md) | Edit groups | Tool documentation |
| [edit-groups-adding-a-tool.md](edit-groups-adding-a-tool.md) | Edit groups/Adding a tool | Integration guide |
| [bots.md](bots.md) | Bots | Official policy |
| [requests-for-permissions-bot.md](requests-for-permissions-bot.md) | Requests for permissions/Bot | Request venue |
| [notability.md](notability.md) | Notability | Official policy |
| [api-etiquette.md](api-etiquette.md) | API:Etiquette (+ maxlag) | API guidelines |

**What to edit** — what a lexeme sense may be, and what we may put in it:

| File | Page | Status |
|------|------|--------|
| [lexicographical-notability.md](lexicographical-notability.md) | Lexicographical data/Notability | Documentation (no policy banner) |
| [senses.md](senses.md) | Lexicographical data/Documentation/Senses | Community documentation |
| [lexeme-data-model.md](lexeme-data-model.md) | Lexicographical data/Glossary + Extension:WikibaseLexeme/Data Model | Glossary + living document |

Each summary was written from the page's **raw wikitext** (fetched via
`action=raw`), so quoted phrasings and numbers are taken from the source rather
than a lossy re-render. They are still condensed — check the source page before
relying on exact wording, and re-check status (the Mass-editing RfC was an open
vote at the retrieval date and may have been adopted or rejected since).

Note the asymmetry in the second table: the lexicographical pages are
**documentation, not adopted policy** — none of them carries a policy or
guideline banner. They describe practice and are what a BRFA reviewer will cite,
but they are not enforceable the way `notability.md` and `bots.md` are.
